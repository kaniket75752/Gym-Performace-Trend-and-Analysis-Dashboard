# Gym-Performace-Trend-and-Analysis-Dashboard
The Gym performace &amp; Analytics Dashboard is an interactive Power BI project designed to analyze gym member data, revenue performance, and health metrics.

#Key Insights
Active members are close to inactive → retention needs improvement
Certain membership plans (like yearly/quarterly) generate higher revenue
BMI analysis shows some members fall into unhealthy categories
Specific age groups dominate the gym (e.g., 26–35)
Revenue trend depends directly on membership growth

#Benefits of Dashboard
Helps gym management make data-driven decisions
Improves member retention strategies
Enables health monitoring using BMI
Identifies popular membership plans
Provides personalized workout & diet suggestions
Saves time compared to manual analysis
